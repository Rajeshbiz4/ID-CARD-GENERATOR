FACULTY CRUD
------------
Backend APIs:
GET    /api/faculty
POST   /api/faculty
GET    /api/faculty/:id
PUT    /api/faculty/:id
DELETE /api/faculty/:id

Only these are mandatory:
- Name
- Faculty / Staff Type

Other fields are optional:
- Employee ID
- Designation
- Department
- Mobile
- Emergency Contact
- Blood Group
- DOB

- Qualification
- Address

- Status

- Other

MARATHI

The Marathi text is stored exactly as entered.

PHOTO
-----
Faculty photo uses the existing GridFS image upload and the existing
student-photo normalization pipeline. No new image storage service is added.

FACULTY ID CARDS
----------------
20 dedicated SYSTEM templates:
- 10 English
- 10 Marathi
- 10 Portrait
- 10 Landscape

Every Faculty template has:
- School logo
- School name
- Faculty photo
- Faculty name
- Employee ID
- Faculty / Staff type
- Designation / Department where applicable
- Mobile / Blood Group where applicable
- QR code
- Principal signature
- Academic year

Template geometry validation:
- 20/20 required elements present
- card bounds: PASS
- element overlap audit: PASS

Faculty templates are separated using:
cardFor: "FACULTY"

Existing student/custom templates remain:
cardFor: "STUDENT"

FACULTY TEMPLATE SETTINGS
-------------------------
APIs:
GET /api/faculty-templates
GET /api/school/faculty-template-settings
PUT /api/school/faculty-template-settings

The selected Faculty template is stored separately from the selected Student
template, so changing a Faculty template does not change the Student template.

FACULTY ID DOWNLOAD
-------------------
New page:
Faculty ID Cards

Supports:
- Faculty selection
- Faculty-template selection
- Live preview
- PNG download
- PDF download

Quota:
- Preview = 0 credit
- Faculty PNG = 1 credit
- Faculty PDF = 1 credit
- Uses the SAME existing school ID-card balance
- Download buttons disable when remaining balance reaches 0

After a successful download the Faculty card status changes to GENERATED.
