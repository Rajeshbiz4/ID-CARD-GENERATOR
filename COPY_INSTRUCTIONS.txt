SIDEBAR SELECTION FIX

Replace:
frontend/src/Layout.jsx

Problem:
On /school/students/new both "Students" and "Add Student" were selected because
the previous active check used startsWith("/school/students").

Fix:
The sidebar now finds all matching menu routes and selects only the longest /
most specific route.

Result:
- /school/students       -> Students selected
- /school/students/new   -> Add Student selected
- /school/students/:id/edit -> Students selected
- other menu routes      -> only their matching item selected

cd frontend
npm run dev
